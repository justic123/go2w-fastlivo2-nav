## 历史结论（旧取图运动数据，已由上述新测试更新）

**移动 LIO/LIVO 尚未通过，不能用于导航。** 实际接入 XT16 数据链路；开启 IMU 时运动发散，关闭 IMU 的纯雷达100秒诊断未出现爆炸式漂移。最大位置模长1.319m不是定位误差；没有地面真值或官方后端同路线精度对照。

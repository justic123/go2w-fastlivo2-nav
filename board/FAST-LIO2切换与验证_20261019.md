## 构建与复现

在新目录取上述官方源码和精确子模块，核对 commit，应用 `board/native/fastlio2-xt16.patch`。应用后六个修改文件 SHA 必须与清单一致；不得在正在运行的 release 上覆盖构建。

```bash
# 在板端新 release 中准备 ws/src/FAST_LIO，再由现有标定生成配置
python3 board/fastlio_config.py --from-livo board/calibration/livo.yaml --output /绝对路径/新release/fastlio.yaml
bash board/build_fastlio2.sh /绝对路径/新release
```

脚本要求新的 build/devel、6GiB构建余量，使用已有 ROS Noetic 与依赖，不安装系统软件。ARM Release、4线程、单编译任务；Livox CustomMsg 输入不参与此 XT16 构建。编译后执行合成 XT16 输入检查，不接传感器、不调用 SDK。

录包回放工具 `board/replay_fastlio2.py` 要求先停实况采集和融合，使用独立 ROS master（默认11431），只发布记录中的 points/imu，不启动真实驱动、相机或运动。不得把该工具指向实况 master。

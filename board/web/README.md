## 登录与启动

访问码与 SSH 密码不同。项目目录运行：

```bash
bash 网页控制台.sh key
```

输入 SSH/sudo 密码后可看到网页访问码，在网页中输入一次即可。访问码不进入 Git、迁移包或日志，登录会话最长12小时；重启网页服务后需重新登录。只在可信机器人局域网使用，未配置公网访问或HTTPS。

网页已安装为板端 `go2w-web.service`，开机自动提供页面和只读显示，**不自动启动建图、导航任务或运动**。

```bash
bash 网页控制台.sh status
bash 网页控制台.sh start
bash 网页控制台.sh stop
bash 网页控制台.sh restart
```

也可以SSH到机器人 `/home/unitree/fast_livo2_port/onboard/current` 执行相同命令。首次部署使用 `bash 网页控制台.sh install`。无需在电脑运行网页服务器。

## 使用顺序

### 继续使用旧图

1. 选择旧地图，点击“加载所选地图”。看到旧图不代表定位已恢复。
2. 机器狗保持静止，点击“在地图标记当前位置与朝向”。在地图实际位置按下，沿机头方向拖出箭头，松开后确认。
3. 等待匹配成功，顶部“旧图定位”正常；核对橙色机头箭头与实机位置方向一致。自动恢复按钮可不提供人工位置尝试全局匹配，存在歧义仍会拒绝。
4. 选择已有目标，点击“预演路线”，检查二维图上的规划路线。
5. 点击“开始导航”并确认。预演有效期60秒，预演后移动实机或修改目标需要重新预演。

### 新扫图

1. 站稳静止后点击“开始新扫图”，确认。现有地图/目标先备份，新融合会话重新初始化。
2. 日志提示扫图开始后，遥控采集整条路线。
3. 停稳后点击“结束并保存”，等待地图保存和定位验证通过。
4. 输入目标名称，用“记录当前位置”，或“地图标点”拖出目标位置和朝向。地图标点只存数据，不发运动指令。
5. 预演、确认、执行。

### 多途经点

选择点并依次“添加到路线”；用每个标签的“←”调整顺序，用“×”移除。允许重复经过同一个点。保存路线后预演整条路线，最后显式执行。

每点需达到现有位置与朝向条件并停稳，默认停留2秒后自动继续。某段失败则停止剩余路线。可将末点设为人工接管点：到点完成模式切换并停稳后结束自动任务，不自动续跑；接管点后还有其他目标会被拒绝。仍不支持自动跨连续楼梯。

## 显示含义

- **二维导航**：旧图未定位时仅显示静态障碍图与已存目标；定位成功后叠加实时全局膨胀代价图、规划路线、机头方向，可勾选局部代价图。过期的位姿与路径不会当作实时数据显示。
- **三维点云**：支持保存的RGB彩色地图与实时RGB观测；旧地图缺少RGB文件时显示灰色几何底图，定位有效时可叠加当前彩色观测。保存几何抽样至最多40万点，RGB缓存最多40万点，浏览器实时几何累计超过40万点时增大显示体素。这些是显示限制，不会修改FAST-LIVO2保存地图的精度。关闭或刷新页面会清空浏览器临时累计几何点，板端已保存地图和RGB缓存保留。
- **广角相机**：复用原有JPEG话题，以约2Hz显示，未额外启动SDK取图。画面显示频率不等于算法图像输入频率；后者仍为板端5Hz配置。
- 鼠标滚轮缩放、二维拖动平移、三维拖动旋转，“适应地图”重新居中。默认适应已观测区域。
- 小窗口下相机和运行状态移到地图下方；放大浏览器窗口可同时看到右侧相机。

## 停止、互斥与断连

“停止导航”独立于其他操作队列，取消本项目的当前运动任务；日志会给出取消反馈，仍需现场确认停稳。启动真实运动必须经过原有预演、输入健康、会话绑定和碰撞保护。网页不发布裸 `cmd_vel`，不绕过现有保护程序。

网页发起运动时，控制页面每秒续约；超过5秒无续约会请求停车，底层运动看门狗仍然保留。页面挂起、笔记本休眠或切后台也可能触发此行为。不能把网络停车替代遥控接管。当前停车请求后旧页面待提交动作会失效，必须刷新状态重新操作。

网页和原有交互菜单共享操作锁。提示“交互菜单正在占用控制权”时，在终端退出旧菜单，不要同时使用两套界面控制。退出菜单不等于停止定位。

## 到点模式与操作顺序

新扫图 → 停稳并结束保存 → 记录目标 → 遥控离开并停稳 → 预演 → 确认导航。保存验证成功后不要重复恢复定位；旧地图恢复只用于定位未就绪时。匹配存在歧义仍会拒绝，需重新核对地图位置与朝向。

新建点使用“新点到点动作”；编辑已有点使用“所选目标的到点动作”，保存后重新预演。途经点列表显示每个点的设置。2026-10-16 已在当前 Go2W 完成默认→普通越障→默认的原地实机校验并启用：到点停稳后调用切换，等待新鲜模式反馈和再次停稳后才继续。其他机器需单独校验。模式切换不代表连续楼梯导航已验证。

相机复用板端 JPEG 话题，不重复请求 SDK；网页相机独立刷新。重启扫图导致 ROS 主服务变化或相机订阅失活时，网页服务自动重连相机订阅，不重启融合。过期画面会变暗并提示中断。

板端融合现由独立的 go2w-fusion-board-*.service 管理；网页重启不再清理融合进程。融合启动仍由操作触发，不开机自动运动。网页修复后已验证重启网页时融合 PID 与会话保持不变。当前旧地图匹配失败需要重新提供定位提示，不能直接执行导航。

## 添加点、路线与三维视角（2026-10-16 修订）

- 新点：填写名称和“新点到点动作”，选择“记录当前位置”（需定位正常）或“在地图添加点”（已保存地图即可）。地图标点需按住位置并拖出朝向箭头；单击会提示继续拖动。保存成功后自动选中新点，可继续添加下一个。
- 已有点：在“选择目标”中选中，再修改“所选目标的到点动作”并保存。它与新点动作互不影响。同名新点必须再次确认覆盖；若其他操作已改过此点，旧覆盖确认失效。
- 多点：逐个添加目标、调整顺序，再保存路线。只有后台完成保存才清除草稿状态；失败保留草稿。一个点请使用单点导航，多点路线至少两个点。“清空编辑”后还需“保存清空路线”才会清空已保存路线。换地图会清除旧图路线草稿。
- 三维：左键拖动旋转；右键、中键或 Shift＋左键拖动平移；触控板可先点击“平移：开”再单指拖动。滚轮缩放，“适应地图”重新居中，“重置视角”恢复默认方向并居中。
- 三维位置（2026-10-18）：橙色箭头表示融合参考点和机头+X方向；点击“定位机器人”将视角移到当前位置，不会使机器人运动。蓝点为已保存目标，路线为当前高度平面投影，不表示可上下楼梯的三维路径。定位失效、输入过期或地图/会话不匹配时隐藏实时标记。
- “执行整条路线”下方会显示禁止执行的具体原因，包括未保存、预演过期、导航未就绪和数据年龄超限。预演有效期60秒；每次执行失败或移动后重新预演。看到历史路径不代表运动许可仍有效。
- 界面展示成功以后台任务完成为准；请求提交不等于保存完成。模式能力按当前板端实机校验证据显示；未校验机器仍拒绝自动切换。

## 启动未完成与历史画面

界面中的“最近一次操作”可能是历史日志，不代表当前仍在执行。地图或相机输入过期会明确标注；旧图未定位时保留静态底图，但不显示成实时定位。服务从终端重新启动后，实时机头箭头使用当前输入会话核对。

扫图启动失败会显示“扫图启动未完成”，查看原因后重新启动即可；原有已保存地图不会因此删除。若“结束并保存”已经生成地图、但随后的定位验证失败，地图会保留在列表中，可选择并重新恢复定位，不必因为验证失败而重扫。冷启动等待上限为60秒（含旧图验证时90秒），超时或子进程退出会明确失败；这不限制扫图时长，也不放宽运动时的数据新鲜度保护。

### “记录当前位置”按钮灰色（2026-10-18）

此按钮保存的是已选地图中的实测位姿，需要融合、导航输入和旧图定位同时有效。仅显示旧地图或实时点云并不代表旧图定位成功。按钮下方现在显示具体未满足条件：未选择地图、正在扫图、融合/导航输入未就绪、旧图定位未通过、正在执行操作或网页断线。

若自动恢复旧图失败，保持静止，点击“去标记当前位置与朝向”，在二维地图上按住机器狗实际位置并沿实际机头方向拖动。匹配通过后按钮自动启用；核对箭头，再填写目标名称、记录当前位置。已有地图和目标不受本次界面修复影响。没有定位时可使用“在地图添加点”指定地图目标，但仍须完成重定位才能导航。不要通过放宽定位门槛或套用本轮临时坐标来强行记录。

### 地图删除与恢复、扫图启动修复（2026-10-18）

“地图”区选择要删除的地图，点“删除所选地图（可恢复）”，确认名称后移入板端 `navigation/mppi/maps-trash/<记录ID>/map`。已保存目标与路线文件随地图保留；当前地图被删除时先停Nav2、清除选择及旧预演，FAST-LIVO2不重启。扫图、保存、重定位或运动任务进行中不能删除。地图内容自确认前发生变化也拒绝删除。展开“地图回收站”可恢复；同名地图存在时拒绝覆盖，恢复后需加载和重新定位。没有永久清空功能。

快速启停曾因TCP连接TIME_WAIT被普通bind探测误判为占用，现探测采用与实际服务一致的SO_REUSEADDR；真实监听进程仍阻止重复启动。Nav2启动期允许最多40秒等待生命周期激活与连续1秒新鲜输入，完成前标记warming_up，不允许导航。进入running后的0.5秒持续输入异常退出和运动端各项过期停车阈值保持不变。网页还能显示命令行持有的操作锁，避免另一入口正在启动时误显示“初始化已中断”。

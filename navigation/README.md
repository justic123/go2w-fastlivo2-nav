# LIVO短距离点到点试验入口

当前操作请读[无障碍点到点测试使用说明](../无障碍点到点测试使用说明.md)。点到点模式现为Python 8秒 / C++ 8.5秒上限、停车后观察5秒；下文5秒/5.5秒为历史试验配置。

> 当前能力与下一阶段以[能力边界与推进路线](能力边界与推进路线.md)为准。下文保留分阶段试验记录；早期“尚未到点”的描述已被后面的20厘米实机结果更新。1米卷尺试验是遥控定位验证，不是自主导航。

默认模式只预演，不发送RPC。SportClient与Go2-W兼容关系、机体坐标系速度与StopMove语义已核对用户给的官方文档：https://support.unitree.com/home/zh/Go2-W_developer/sports_services 。本机SDK没有文档中的GetState方法，使用rt/lf/sportmodestate只读订阅检查运行状态。

## 当前范围

point_trial.py接实时camera_init里程计，建立前方0.3m目标，仅做短距离直行与小幅保持朝向。不是全局规划器，不提供绕障、已保存地图重定位或完整Nav2导航。官方inspection程序调用的是宇树原生SLAM服务，尚未接入LIVO。

输入质量：3秒稳定初态，位姿新鲜度0.85秒，点云/IMU新鲜度0.4秒，IMU间隔20ms，位姿跳变0.15m。控制上限0.05m/s、角速度0.1rad/s、最长12秒。横向偏离0.1m或朝向偏离0.2rad停止，到点容差4cm并持续0.8秒。

使用候选雷达->IMU外参检查前方x=0.35..1.1m、|y|<0.4m、z=-0.1..0.8m点云，有点即拒绝；这只是保守试验门限，不是经过验证的障碍物/悬崖检测器，不替代现场监护。

sport_guard.cpp通过本地管道接受命令，默认不初始化DDS客户端、不发指令。--execute才发送Go2 SportClient Move/StopMove；正常执行不切换步态、站立模式或阻尼；独立 --balance 入口可调用一次 BalanceStand，已实测一次返回0。检查命令单调时钟年龄<=0.15秒、速度范围，输入超时0.3秒停止，进程最长20秒，EOF/信号/错误调用StopMove。断电、进程强杀及SDK停止调用失败仍需要现场遥控器接管。

## 已验证

6个坐标/到点/越界策略测试通过；板端C++编译通过；默认预演检查有效命令、过期命令、超速、输入超时四种情况，均未发真实命令。运控只读订阅收到mode=1、gait_type=0、零速度。

首轮实时LIVO预演point-preview-01收到稳定位置，但前方检测区内514个点，拒绝运动，commands=0。随后检查点集中在候选机体系前方0.36..0.59m、左侧0.355..0.40m，来源待现场确认，不据此自行缩小门限。

## 运行

在板端 source /opt/ros/noetic/setup.bash，并设置ROS_MASTER_URI=http://127.0.0.1:11321；先启动180秒LIVO采集入口，再运行navigation/point_trial.py --output <全新目录> 做预演。实际执行还需加--execute，仅限已确认现场无人障碍物、网线余量充分且遥控器可接管的短距离试验。

已进行真实Move/StopMove调用，但尚未完成实机到点，返回码0不能作为实际运动证据。point-execute-01和03各执行12秒，最高0.05m/s；用户均未观察到移动，03估计位置变化约6.5毫米。02仅6条命令后输入新鲜度停机，原日志未区分超时来源。已添加逐路输入年龄和失败时间记录，并限制BLAS线程；03完整执行未触发输入超时。

用户提出速度可能过低，新增 --startup-test：速度上限0.10m/s、控制时长2秒；C++独立截止2.5秒。默认预演通过 --preview-startup 检查同一限速但不初始化DDS。正常模式速度不变。起步试验不等于完成点到点导航。

最新实机结果：point-startup-execute-01在2秒内发40条指令，LIVO估计前移8.8厘米，用户确认已前移并停住。停止调用返回0，随后运控反馈零速度。短时起步成功，30厘米到点尚未完成。

## 距离触发停车试验（point-test）

--point-test 使用恒定0.10m/s，避免比例减速降到未起步区；距离剩余4厘米时关闭指令管道，立即由guard调用StopMove。Python运动上限5秒、guard独立上限5.5秒；停车后只观察2.5秒，至少3个新位姿，末3点轴向范围小于3厘米且目标平面误差不超过8厘米才标记goal reached。只有距离触发停止才可能标记成功，时间到停不能转记到点。实际停止与距离仍需现场观察，估计误差不等于真值误差。

point-goal-execute-01目标0.3米：99条指令，输入/障碍检查正常，5秒时限停止；停车后LIVO估计前移0.248米，距目标约0.052米。未触发距离停车条件，不算自动到点通过。

point-goal-execute-02目标0.2米：70条指令，距离条件触发StopMove，停车后估计前移0.182米、目标误差约0.018米，判定goal reached。用户确认再次前移并自动停住。详情见../建图到点测试_2026-09-27.md。

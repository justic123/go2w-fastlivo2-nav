# 定位重复性测试（只读，不发送运动指令）

目的：先人工归位，区分 FAST-LIVO2 原始位姿漂移与旧地图重定位修正，再决定控制器优化。使用同一固定机身参考点及地面朝向线；导航 base 是当前 FAST-LIVO2 的 IMU 参考，不能把屏幕箭头尖端当机身测量点。返回时同时对齐位置和朝向，以减少参考点偏置影响。

保持当前 FAST-LIVO2 会话不变。确认 MPPI 输入和旧地图定位健康后：

```bash
/usr/bin/python3 navigation/mppi/measure_repeatability.py --label baseline
```

保存输出的 JSON 路径。遥控低速离开约1米，停稳；再人工回到标记位置和朝向，停稳至少10秒。不要用自主导航来代替本测试的人工归位。

```bash
/usr/bin/python3 navigation/mppi/measure_repeatability.py --label return-1 --reference /完整路径/repeatability-基准时间.json
```

重复3轮，每轮记录人工归位的前后、左右、朝向残差（未测就明确写未测）。脚本同时输出原始 camera_init 与 map 坐标的差值，以及基准机身方向的 forward/left、朝向差；这些是软件重复性，不能单独称作真实精度。

脚本不修改导航返回目标、不发送 ROS 目标或 SDK 指令。检查数据时效、会话一致性、唯一位姿样本数及静止波动；不满足即拒绝测量。结果写入当前 runs 目录，不提交房间数据到 GitHub。

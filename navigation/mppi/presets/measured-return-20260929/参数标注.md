# 实测返回参数冻结版

标签：v0.1.1-measured-return-20260929。导航配置副本是本目录params.yaml，实际运行仍读取navigation/mppi/params.yaml。manifest.json记录控制及融合配置摘要校验；复制配置前必须停止相关导航服务。

| 参数 | 保留值 | 用途 |
|---|---:|---|
| xy_goal_tolerance | 0.08 m | 平面位置到点容差 |
| yaw_goal_tolerance | 0.12 rad（6.88°） | 朝向到点容差 |
| stateful | false | 同时核对位置与朝向 |
| controller_frequency | 20 Hz | 控制计算频率 |
| vx_max / vx_min | 0.20 / -0.10 m/s | 前进/后退速度范围 |
| wz_max | 0.8 rad/s | 角速度上限 |
| time_steps × model_dt | 40 × 0.05 s | MPPI预测时域2秒 |
| footprint | 0.75 × 0.44 m | 实测轮足外缘包络，当前以融合机身参考居中近似 |
| footprint_padding | 0.05 m | 每侧安全余量 |
| global/local resolution | 0.10 / 0.05 m | 全局/局部代价地图栅格 |
| VelocityDeadbandCritic | weight 35，vx阈值0.08 m/s | 对低效小速度施加代价，不强行提升输出 |

全局NavFn A*、局部MPPI DiffDrive运动模型；通过高层SportClient发送速度。velocity_smoother的OPEN_LOOP是速度平滑器使用上一指令做平滑，不代表整个导航按时间开环行驶；导航仍使用实时融合位姿。

单轮实测：软件7.66 cm、3.18°；用户测得位置约7 cm，朝向仅目测相近。保留此参数，不改为5 cm。尚未完成多起点统计、障碍绕行验证和长时间稳定性验收。

已知限制：旧地图匹配可能触发保护退出；长时间运行出现源时间戳超前100 ms而停机，尚未根治；本轮演示前必须检查当前会话健康，失效时按重新初始化流程恢复，不得放宽过期保护。地图/目标不属于参数，不能跨会话直接复制旧目标。
